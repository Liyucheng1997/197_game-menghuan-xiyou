# 梦幻西游 · 经典端游方向单机原型

当前版本：**v1.1**。 [在线试玩](https://liyucheng1997.github.io/197_game-menghuan-xiyou/) · [版本说明](CHANGELOG.md)

本项目正在从 Emoji 小游戏改造成经典电脑版方向的单机原型。**已接入官网公开场景图、原声音乐，以及历史资料页的经典角色 GIF，尚未达到 1∶1 复刻。** 具体历史年份尚未指定，玩法数值为本地试玩配置。所有实际素材出处与限制见 [assets/SOURCES.md](assets/SOURCES.md)，本地校验值见 [assets/inventory.json](assets/inventory.json)。

## 运行

在项目目录运行 `python -m http.server 8195`，浏览器打开 http://localhost:8195 。请保留同目录的 `classic.css`、`classic.js`、`world.js` 与 `assets` 文件夹。进度存于浏览器 localStorage，不同网址/浏览器的存档互不共享。创建/继续游戏后开始播放原声，右下角音符可静音。

## 本轮已实现

- 960×720、4∶3 界面，自适应缩放；左上地图坐标、右上气血魔法、底部功能栏、任务追踪。
- 建邺城出生；长安城 ↔ 江南野外 ↔ 建邺城 ↔ 东海湾的地图连接；网格寻路。长安、江南野外、东海湾使用官网无人场景图，跟随人物滚动，通行道路手工适配。建邺背景仍为占位，地图面板可查看历史小地图。
- 剑侠客、龙太子、玄彩娥使用公开经典角色GIF（33/37/35帧），运行时将黑底透明合成；这只是展示动作，并非完整走跑战斗动作集。选角/头像为官方宣传立绘，标题使用官网标志。
- 东海湾遇大海龟/海毛虫，江南野外遇巨蛙/树怪/强盗；野外行走随机遇敌。

- 横扫改为同一目标三连击，要求气血高于50%，消耗上限10%气血，下一回合休息；龙卷雨击、龙腾、日光华、普度众生提供可执行逻辑。
- 人物和召唤兽分开下达指令，按速度结算；防御从回合开始生效；普度具有持续恢复；修正捕捉后新旧宠物血量串写。
- 商店、客栈、背包、捕捉、升级、存档沿用并兼容；增加可领取/追踪/交付的巡逻试玩任务。
- 关闭伪造的世界聊天。六首官网原声已下载到本地，按地图、战斗切换；现有操作音效仍是合成占位音效。

## 操作

点击地面移动；点击NPC自动走近后对话；点击蓝色出口切换地图。Tab 打开地图并可导航至相邻出口。Alt+E 背包、Alt+P 召唤兽、Alt+W 法术、Alt+Q 任务；Esc 关闭弹窗。战斗中先下人物指令，再下召唤兽指令。

## 原版资源接入

编辑 `assets/manifest.js`，填写你有权使用的本地文件路径：

```js
window.CLASSIC_ASSETS = {
  maps: { changan: 'assets/maps/changan.png' },
  actors: { jxk: 'assets/actors/jxk.gif' },
  music: { changan: 'assets/music/changan.mp3', battle: 'assets/music/battle.mp3' },
  effects: { hsqj: 'assets/effects/hsqj.gif' }
};
```

地图键：`changan / jianye / jiaowai / donghai`。人物键：`jxk / ltz / xce`，NPC 键：`yao / inn / bing`，怪物键见 `MONSTERS`。技能键：`hsqj / ljyj / longteng / rgh / pdzs`。

原图在固定大小的世界容器中显示，相机随玩家移动；原始文件未重采样或裁切。角色为浏览器播放的GIF，黑底通过SVG滤镜在运行时处理。尚不支持原客户端地图分块、八方向动作、精灵帧表、UI切片或原客户端资源格式。地图尺寸、NPC、出口与通行走廊配置在 `world.js`；新地图需要同步调整这些数据。
