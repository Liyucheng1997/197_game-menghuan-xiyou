# 梦幻西游 · 怀旧版 🏮

一个单文件网页小游戏，致敬童年的《梦幻西游》。无需安装、无需联网，双击 `index.html` 即可回到长安城。

## 怎么玩

直接用浏览器打开 `index.html` 就行。进度自动保存在浏览器本地（localStorage）。

- **创建角色**：剑侠客（大唐官府）/ 逍遥生（龙宫）/ 玄彩娥（普陀山），各有门派技能
- **长安城**：点击地面移动，找药店老板买药、客栈老板娘住店、守城老兵唠嗑
- **建邺城郊外**：走路踩暗雷遇敌，海毛虫、巨蛙、大海龟、蟹将、树怪出没
- **回合制战斗**：攻击 / 法术 / 防御 / 道具 / 捕捉 / 逃跑，按速度决定出手顺序
- **抓宠**：战斗中选「捕捉」，妖怪血越少越容易抓；抓到的召唤兽会随你出战、升级
- **右上角 🔊**：来一段小曲儿

## 技术说明

纯手写 HTML + CSS + JavaScript，零依赖，单文件。人物和怪物用 emoji 呈现，音效由 Web Audio API 实时合成。

本地开发预览：

```bash
python -m http.server 8195
# 然后访问 http://localhost:8195
```
