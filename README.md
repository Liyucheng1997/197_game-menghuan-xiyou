# 梦幻西游 · Q版

当前版本：**v2.4**。 [在线试玩（账号 + 云存档）](https://mhxy.liyucheng.me) · [GitHub Pages 离线版](https://liyucheng1997.github.io/197_game-menghuan-xiyou/) · [版本说明](CHANGELOG.md)

一款浏览器单机回合制 RPG，致敬经典电脑版《梦幻西游》。所有角色、怪物、NPC、地图、建筑与技能特效均由程序实时绘制成 Q 版风格，音乐使用官网公开原声。无需安装，打开网页即可游玩。登录账号后进度自动保存到服务器，清除浏览器数据或换设备都不会丢失。

## 运行

```bash
npm start        # 即 node server.js，需要 Node 22.13+，无需安装依赖
```

然后打开 http://localhost:8195 。游戏使用 ES Module，必须通过 HTTP 访问，直接双击 `index.html` 无法运行。

`server.js` 同时提供游戏页面和账号接口，账号与存档保存在 `data/mhxy.db`（SQLite）。用 `python3 -m http.server` 等纯静态服务器（或 GitHub Pages）打开时，游戏自动进入离线模式，存档只保存在当前浏览器。

## 账号与云存档

- 首页注册/登录后才能开始游戏；首次登录时，浏览器中已有的存档会自动迁移到账号。本地缓存与云端存档自动取较新的一份。
- 存档变化后约 1 秒上传，关闭页面时也会补发；上传失败会暂存本机，每 20 秒重试一次。系统面板的「删除存档」会同时删除云端存档。
- 接口：`POST /api/register`、`POST /api/login`、`POST /api/logout`、`GET /api/me`、`GET|PUT|DELETE /api/save`。
- 安全：密码用 scrypt 加盐哈希保存；会话为 HttpOnly Cookie，有效期 30 天；同一 IP 登录失败 10 次后锁定 15 分钟。服务端只对外提供 `index.html`、`style.css`、`src/` 与 `assets/`，数据库和部署文件无法通过网址访问。
- 防丢档：每个账号在 `save_history` 表中保留最近 30 份历史存档（最多每 5 分钟一份，删档前也会留一份）；数据库每天快照到 `data/backups/`，保留 14 天。

## 部署

线上地址 https://mhxy.liyucheng.me ，运行在 reader-server 的 `/opt/apps/mhxy`（systemd 服务 `app-mhxy`，端口 4195，Nginx 反代 + Let's Encrypt 证书）。

**自动部署**：推送到 GitHub 的 `master` 分支即可。`.github/workflows/deploy.yml` 会先跑 `npm test`，通过后把 `index.html`、`style.css`、`src/`、`assets/`、`server.js` 打包发到服务器，由 `/usr/local/bin/mhxy-deploy`（源文件 `deploy/mhxy-deploy`）校验、替换程序文件并重启服务，最后检查线上地址。`data/` 中的账号与存档不受影响。GitHub Pages 离线版也同时从 `master` 更新。进度可在仓库的 Actions 页查看，也可以在那里手动重新运行。

- 部署密钥保存在仓库 Secret `MHXY_DEPLOY_KEY`；服务器 `authorized_keys` 中该公钥带 `command="/usr/local/bin/mhxy-deploy",restrict`，只能执行发布，不能登录 shell 或转发端口。需要更换时重新生成一对密钥，替换这两处即可。
- 手动部署（备用）：`npm run deploy`，使用本机的 `reader-server` SSH 配置。首次部署到新服务器时使用 `bash deploy/deploy.sh --init`，它会同时安装 systemd 服务、Nginx 站点、HTTPS 证书和 `mhxy-deploy` 发布入口。

## 游戏内容

**角色与门派**：8 个角色，分属人、仙、魔三族：剑侠客、逍遥生、飞燕女、英女侠、龙太子、玄彩娥、巨魔王、狐美人。共 12 个门派，每派 3 个主动技能和 1 个心法：

| 种族 | 门派 |
|---|---|
| 人族 | 大唐官府（横扫千军）· 化生寺（推气过宫）· 女儿村（满天花雨）· 方寸山（五雷咒/催眠符） |
| 仙族 | 龙宫（龙卷雨击）· 普陀山（普度众生）· 天宫（五雷轰顶）· 五庄观（日月乾坤） |
| 魔族 | 魔王寨（飞砂走石）· 狮驼岭（鹰击/变身）· 盘丝洞（天罗地网）· 阴曹地府（阎罗令/尸腐毒） |

**地图**：建邺城 → 东海湾 → 沉船 → 江南野外 → 长安城 → 大唐国境 → 大唐境外 → 白骨洞 / 花果山 → 东海龙宫 → 北俱芦洲 → 火焰山 → 无底洞 → 南天门 → 幽冥地府 → 小雷音寺，另有 12 个门派场景。各地图之间由传送圈相连，驿站可直达去过的远方地图。

**怪物**：海毛虫、大海龟、巨蛙、虾兵、蟹将、野鬼、树怪、野猪、强盗、赌徒、山贼、老虎、黑熊、花妖、狐狸精、羊头怪、蛤蟆精、骷髅怪、牛妖、僵尸、蜘蛛精、冤魂、巨力神猿、长眉灵猴、天将，以及 50 级以后的巡海夜叉、鲛人、雪狼、冰妖、火精、牛魔将、鼠精、蝎子精、妖兵、雷公、阴兵、无常、妖僧、魔猴等。首领有商人的鬼魂、山贼头子、妖风、白骨精三形态，以及「七大圣篇」的混世魔王、九头虫、蛟魔王、红孩儿、铁扇公主、魔化牛王、地涌夫人、鹏魔王、狮驼王、禺狨王、黄眉大王、六耳猕猴。

**玩法**：

- 回合制战斗，队伍最多 5 人（主角、3 名伙伴、1 只召唤兽）。按速度出手，可以攻击、法术、道具、防御、捕捉、召唤、逃跑，也可以开启自动战斗。战斗中会出现封印、中毒、持续回复、增益减益、鬼魂复活、反击、连击、暴击、吸血、神佑等效果。
- 召唤兽：野外战斗中可以捕捉，偶尔会遇到成长更高的「宝宝」。每只召唤兽的成长和技能各不相同，最多携带 4 只。
- 伙伴：主线剧情会送两名伙伴，其余可以在长安城侠义堂招募。伙伴等级与主角同步，按门派定位自动行动（治疗、封印、法术或物理）。
- 成长：升级获得属性点，可以按门派推荐自动加点；6 个装备部位、16 档装备；门派技能在师父处学习。
- 装备（2.4）：分普通、精良、稀有、史诗、传说、神器六种品质，品质越高基础属性越高、附加属性越多。史诗以上必带**特效**（神佑、嗜血、暴击、狂暴、追击、破甲、反震、法暴、法连、法穿、护体、回春、冥想、迅捷、强体、聚宝、福缘、寻宝、简易、无级别限制），传说、神器大多附带**特技**（破血狂攻、弱点击破、天崩地裂、九霄雷鸣、罗汉金钟、野兽之力、流云诀、四海升平、晶清诀、慈航普渡、凝滞术、气疗术、放下屠刀），特技在战斗「法术」里使用，每场有次数限制。
- 开装备：野外与任务掉落的装备是「未鉴定」的，在背包里鉴定（或一键鉴定）时揭晓；神秘宝箱、神兵宝匣、天工宝匣打开就是一件装备；长安城兵器铺、服饰店、首饰店可以花银两**打造**（十连必出史诗以上）；用灵犀玉**洗练**附加属性、特技、特效，新旧二选一。
- 主线剧情共 40 章。第一部（1~40 级）：初入江湖 → 拜师学艺 → 国境山贼 → 境外妖风 → 三打白骨精。第二部「七大圣」（40~150 级）：花果山 → 东海龙宫 → 北俱芦洲 → 火焰山 → 无底洞 → 南天门 → 幽冥地府 → 真假美猴王。
- 等级上限 150。69、89、109、129 级是瓶颈，经验先储存，到长安城太白金星处战胜心魔渡劫后继续升级。
- 日常任务：
  - 师门任务：送信、寻物、巡逻、示威，每 10 环有额外奖励。
  - 钟馗抓鬼：15 级开放，每 10 只有额外奖励。
  - 店小二宝图：10 级开放，打败强盗获得藏宝图，挖宝可能得到银两、装备、道具或妖怪。
  - 连续任务：在活动面板（H）开启后，师门、抓鬼完成会自动接下一个并寻路。
- 挑战与活动（活动面板 H，NPC 在长安城南边）：
  - 镇妖塔（30 级）：125 层爬塔，首通奖励，每十层妖王，低层可扫荡。
  - 秘境降妖（40 级，每日 3 次）：五关闯关，每关后三选一祝福，通关开宝箱。
  - 华山论剑（30 级，每日 5 场）：挑战随机「玩家」队伍，积分段位青铜到王者。
  - 三界答题（20 级，每日 10 题）。
  - 天降异象（30 级）：随机出现星宿、聚宝盆精灵和妖王，限时 15 分钟。
- 藏宝阁（B）：仙玉祈愿抽神兽（十连保紫、60 抽保金）、仙玉商城、充值（单机版免费，点击即到账，首充送神兽）、签到、等级礼包、成就、VIP。
- 养成：装备强化 +1~+15、装备洗练、修炼（全队共享）、伙伴升星、魔兽要诀打书、神兽。
- 野外奇遇（2.4）：在野外行走时随机触发——拾金、金元宝、仙人指点、灵泉、残图、路边宝箱、神秘商人、落难小妖、神兵守护、江湖赌客、财神显灵、天工遗宝。
- 便利功能：跨地图自动寻路（点击任务追踪或地图）、小地图、摄妖香、飞行符、客栈休息、非战斗时缓慢回血、自动存档。切换标签页或最小化窗口后游戏继续运行（寻路、自动战斗照常进行）。

## 项目结构

```
index.html / style.css   页面与界面样式
src/main.js              启动、标题、创建角色、主循环、输入
src/data.js              角色、门派、技能、物品、装备、怪物、伙伴等数值
src/stats.js             属性推导
src/battle-core.js       回合制战斗逻辑（与渲染无关，可在 Node 中测试）
src/battle.js            战斗画面、动画、特效、指令界面
src/maps.js              地图构建器、全部地图定义、A* 寻路、跨图路线
src/mapart.js            地块与建筑、树木等物件的程序绘制
src/art.js               Q 版人物与怪物的程序绘制
src/world.js             大地图场景：移动、镜头、NPC、传送、天气
src/game.js              规则：NPC 交互、主线与日常任务、遇敌、奖励
src/story2.js            主线第二部「七大圣」剧情与首领阵容
src/activity.js          渡劫、镇妖塔、秘境、论剑、答题、天降异象、活动面板
src/mall.js              藏宝阁：仙玉、祈愿、商城、充值、签到、成就、VIP
src/loot.js              装备开箱：鉴定、宝箱、打造、洗练、一键出售与揭晓动画
src/qiyu.js              野外奇遇
src/growth.js            装备强化、修炼、伙伴升星
src/panels.js            HUD 与各功能面板
src/cloud.js             账号登录与云存档同步
src/state.js / npcs.js / enemies.js / ui.js / audio.js / util.js
server.js                账号、云存档接口与静态文件服务（零依赖）
deploy/                  systemd、Nginx 配置与一键部署脚本
```

## 测试

```bash
npm test               # Node 内置测试：地图连通、任务引用、战斗规则、平衡、存档、2.3 新玩法、2.4 装备特技特效，以及账号与云存档接口
npm run balance        # 打印各阶段战斗的模拟胜率（含 50~150 级）
npm run test:e2e       # 浏览器端到端：自动打通全部主线（需要 Playwright）
```

另有两个开发预览页：`tests/gallery.html` 展示全部角色与怪物，`tests/maps.html#地图ID,缩放` 预览地图，例如 `tests/maps.html#changan,0.4`。
