# 梦幻西游 · Q版

当前版本：**v2.0**。 [在线试玩](https://liyucheng1997.github.io/197_game-menghuan-xiyou/) · [版本说明](CHANGELOG.md)

一款浏览器单机回合制 RPG，致敬经典电脑版《梦幻西游》。所有角色、怪物、NPC、地图、建筑与技能特效均由程序实时绘制成 Q 版风格，音乐使用官网公开原声。无需安装，打开网页即可游玩，进度自动保存在浏览器本地。

## 运行

```bash
python3 -m http.server 8195   # 或 npm start
```

然后打开 http://localhost:8195 。游戏使用 ES Module，必须通过 HTTP 访问，直接双击 `index.html` 无法运行。

## 游戏内容

**角色与门派**：8 个角色，分属人、仙、魔三族：剑侠客、逍遥生、飞燕女、英女侠、龙太子、玄彩娥、巨魔王、狐美人。共 12 个门派，每派 3 个主动技能和 1 个心法：

| 种族 | 门派 |
|---|---|
| 人族 | 大唐官府（横扫千军）· 化生寺（推气过宫）· 女儿村（满天花雨）· 方寸山（五雷咒/催眠符） |
| 仙族 | 龙宫（龙卷雨击）· 普陀山（普度众生）· 天宫（五雷轰顶）· 五庄观（日月乾坤） |
| 魔族 | 魔王寨（飞砂走石）· 狮驼岭（鹰击/变身）· 盘丝洞（天罗地网）· 阴曹地府（阎罗令/尸腐毒） |

**地图**：建邺城 → 东海湾 → 沉船 → 江南野外 → 长安城 → 大唐国境 → 大唐境外 → 白骨洞 / 花果山，另有 12 个门派场景。各地图之间由传送圈相连。

**怪物**：海毛虫、大海龟、巨蛙、虾兵、蟹将、野鬼、树怪、野猪、强盗、赌徒、山贼、老虎、黑熊、花妖、狐狸精、羊头怪、蛤蟆精、骷髅怪、牛妖、僵尸、蜘蛛精、冤魂、巨力神猿、长眉灵猴、天将等。首领有商人的鬼魂、山贼头子、妖风、白骨精三形态。

**玩法**：

- 回合制战斗，队伍最多 5 人（主角、3 名伙伴、1 只召唤兽）。按速度出手，可以攻击、法术、道具、防御、捕捉、召唤、逃跑，也可以开启自动战斗。战斗中会出现封印、中毒、持续回复、增益减益、鬼魂复活、反击、连击、暴击、吸血、神佑等效果。
- 召唤兽：野外战斗中可以捕捉，偶尔会遇到成长更高的「宝宝」。每只召唤兽的成长和技能各不相同，最多携带 4 只。
- 伙伴：主线剧情会送两名伙伴，其余可以在长安城侠义堂招募。伙伴等级与主角同步，按门派定位自动行动（治疗、封印、法术或物理）。
- 成长：升级获得属性点，可以按门派推荐自动加点；有 6 个装备部位、7 档装备，掉落装备分普通、精良、稀有、史诗四种品质；门派技能在师父处学习。
- 主线剧情共 15 章：初入江湖 → 收服召唤兽 → 渔夫的烦恼 → 沉船冤魂 → 拜师学艺 → 国境山贼 → 擒贼擒王 → 境外妖风 → 三打白骨精。
- 日常任务：
  - 师门任务：送信、寻物、巡逻、示威，每 10 环有额外奖励。
  - 钟馗抓鬼：15 级开放，每 10 只有额外奖励。
  - 店小二宝图：10 级开放，打败强盗获得藏宝图，挖宝可能得到银两、装备、道具或妖怪。
- 便利功能：跨地图自动寻路（点击任务追踪或地图）、小地图、摄妖香、飞行符、客栈休息、非战斗时缓慢回血、自动存档。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | 点击地面，或方向键 |
| 对话 | 点击 NPC，角色会自动走过去 |
| 人物 / 道具 / 召唤兽 / 技能 / 任务 / 队伍 / 地图 | W / E / P / F / Q / T / Tab |
| 战斗指令 | A 攻击、W 法术、E 道具、D 防御、G 捕捉、S 召唤、F 逃跑、Q 自动；右键或 Esc 取消 |

## 项目结构

```
index.html / style.css   页面与界面样式
src/main.js              启动、标题、创建角色、主循环、输入
src/data.js              角色、门派、技能、物品、装备、怪物、伙伴等数值
src/stats.js             属性推导
src/battle-core.js       回合制战斗逻辑（与渲染无关，可在 Node 中测试）
src/battle.js            战斗画面、动画、特效、指令界面
src/maps.js              地图构建器、全部地图定义、A* 寻路、跨图路线
src/mapart.js            地块与建筑、树木等物件的程序绘制
src/art.js               Q 版人物与怪物的程序绘制
src/world.js             大地图场景：移动、镜头、NPC、传送、天气
src/game.js              规则：NPC 交互、主线与日常任务、遇敌、奖励
src/panels.js            HUD 与各功能面板
src/state.js / npcs.js / enemies.js / ui.js / audio.js / util.js
```

## 测试

```bash
npm test               # Node 内置测试：地图连通、任务引用、战斗规则、平衡、存档
npm run balance        # 打印各阶段战斗的模拟胜率
npm run test:e2e       # 浏览器端到端：自动打通全部主线（需要 Playwright）
```

另有两个开发预览页：`tests/gallery.html` 展示全部角色与怪物，`tests/maps.html#地图ID,缩放` 预览地图，例如 `tests/maps.html#changan,0.4`。
